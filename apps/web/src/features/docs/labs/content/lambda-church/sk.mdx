export const parenTerms = [
  "λx.x z λy. x y",
  "(λx.x z) λy.w λw.w y z x",
  "(λz.z) (λy.y y) (λx.x a)",
]

export const evalTerms = [
  "(λz.z) (λy.y y) (λx.x a)",
  "(λx. λy.x y) y",
  "(λz.z) (λz.z z) (λz.z y)",
  "(λx.λy.x y y) (λa.a) b",
  "(λx.λy.x y y) (λy.y) y",
  "(λx.x x) (λy.y x) z",
  "(λx. (λy. (x y)) y) z",
  "((λx.x x) (λy.y)) (λy.y)",
  "((λx. λy.(x y)) (λy.y)) w",
]

export const churchTerms = [
  "test true true false",
  "test false true false",
  "and false true",
  "test (or true false) true false",
  "and (iszero 0) (test (iszero 0) true false)",
  "plus 1 0",
  "plus 3 1",
  "plus 0 3",
  "times 0 2",
  "times 2 0",
  "snd (pair (and true false) 3)",
]

## Ciele

Po tomto cvičení viete: doplniť zátvorky do λ-termov bez zmeny významu, určiť voľné a viazané
premenné, vyhodnotiť λ-termy pomocou β-redukcie (prípadne α- a η-redukcie) a pracovať s Churchovými
kódovaniami booleovských hodnôt, čísel a dvojíc.

Pomôcka: [Úvod, jazyk NBL, λ-kalkul](/docs/lambda-intro) a [Churchove kódovania](/docs/church-encodings).

## Krok 1: Syntaktická analýza termov

Doplňte do každého termu zátvorky tak, aby sa nezmenil jeho význam. Pripomeňte si konvencie:
aplikácia sa zoskupuje zľava a telo abstrakcie siaha čo najďalej doprava.

<LambdaTask type="parens" terms={parenTerms} />

## Krok 2: Voľné a viazané premenné

Pre každý výskyt premennej v termoch z kroku 1 určte, či je voľný, alebo viazaný.

<LambdaTask type="scope" terms={parenTerms} />

## Krok 3: Vyhodnotenie λ-termov

Využitím β-redukcie, prípadne α-redukcie či η-redukcie nájdite normálnu formu každého termu. Výpočet
prebieha úplnou normalizáciou, teda aj vo vnútri abstrakcií. Ak si nie ste istí, môžete výpočet
skúsiť po krokoch.

<LambdaTask type="normal-form" terms={evalTerms} />

## Krok 4: Programovanie v λ-kalkule

V tomto kroku sa používajú štandardné Churchove kódovania z [prednášky](/docs/church-encodings)
(`true`, `false`, `test`, `and`, `or`, `not`, `iszero`, `plus`, `times`, `succ`, `pair`, `fst`, `snd`), pričom
čísla `0`, `1`, `2`, … sú Churchove numerály. Výsledok môžete zapísať ako `true`, `false`, číslo alebo λ-term.

### Úlohy 4.1 – 4.11

Vyhodnoťte výrazy.

<LambdaTask type="church" terms={churchTerms} />

### Úloha 4.12

Definujte operáciu implikácie ako λ-term.

<LambdaTask
  type="define"
  solution="λ p . λ q . p q true"
  tests={[
    ["true true", "true"],
    ["true false", "false"],
    ["false true", "true"],
    ["false false", "true"],
  ]}
/>

### Úloha 4.13

Definujte operáciu XOR ako λ-term.

<LambdaTask
  type="define"
  solution="λ p . λ q . p (not q) q"
  tests={[
    ["true true", "false"],
    ["true false", "true"],
    ["false true", "true"],
    ["false false", "false"],
  ]}
/>

### Úloha 4.14

Definujte operáciu, ktorá pripočíta ku každému číslu 2.

<LambdaTask
  type="define"
  solution="λ n . plus n 2"
  tests={[
    ["0", "2"],
    ["1", "3"],
    ["4", "6"],
  ]}
/>

### Úloha 4.15

Definujte operáciu, ktorá každé číslo vynásobí dvoma a pripočíta 1.

<LambdaTask
  type="define"
  solution="λ n . succ (times n 2)"
  tests={[
    ["0", "1"],
    ["1", "3"],
    ["3", "7"],
  ]}
/>

### Úloha 4.16

Definujte operáciu dvojitej negácie.

<LambdaTask
  type="define"
  solution="λ b . not (not b)"
  tests={[
    ["true", "true"],
    ["false", "false"],
  ]}
/>
