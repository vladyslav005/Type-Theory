## Krok 2: Jednoducho typovaný λ-kalkul

Pri každom terme najprv odvodzovacím stromom overte, či je správne typovaný. Ak áno, aplikujte ho na
vhodné argumenty a vyhodnoťte ho; ak nie, označte to.

### Úloha 2.1

<MathBlock>{"\\lambda x: A \\to B. \\lambda y: A.\\ x\\ y : (A \\to B) \\to A \\to B"}</MathBlock>

Overte, či je správne typovaný v prázdnom typovom kontexte.

<TypingTask id="stlc-1-typing" type="derivation" calculus="stlc" term="λ x : A -> B . λ y : A . x y : (A -> B) -> A -> B" />

Vyhodnoťte ho pre vhodné argumenty (ak je správne typovaný).

<TypingTask
  id="stlc-1-evaluate"
  type="evaluate"
  term="λ x : A -> B . λ y : A . x y : (A -> B) -> A -> B"
  example={"g : A -> B;\na : A;\n(λ x : A -> B . λ y : A . x y) g a"}
/>

### Úloha 2.4

<MathBlock>{"\\lambda x: Bool. \\lambda y: Bool.\\ and\\ x\\ y : Bool \\to Bool \\to Bool"}</MathBlock>

Overte, či je správne typovaný v typovom kontexte <Math>{"\\Gamma = \\{and: Bool \\to Bool \\to Bool\\}"}</Math>.

<TypingTask
  id="stlc-4-typing"
  type="derivation"
  calculus="stlc"
  context="and : Bool -> Bool -> Bool"
  term="λ x : Bool . λ y : Bool . and x y : Bool -> Bool -> Bool"
/>

Vyhodnoťte ho pre vhodné argumenty (ak je správne typovaný). Funkciu `and` môžete nechať ako
premennú z kontextu, alebo ju definovať, napr. `and = λ p : Bool . λ q : Bool . if p then q else false : Bool -> Bool -> Bool;`.

<TypingTask
  id="stlc-4-evaluate"
  type="evaluate"
  context="and : Bool -> Bool -> Bool"
  term="λ x : Bool . λ y : Bool . and x y : Bool -> Bool -> Bool"
  example={"and = λ p : Bool . λ q : Bool . if p then q else false : Bool -> Bool -> Bool;\n(λ x : Bool . λ y : Bool . and x y) true false"}
/>
